EduTool

目标检测数据集查看器

选择标注格式，打开对应的离线查看器。上传本地图片与标注，查看检测框、缩放和拖动画布。文件均在浏览器中处理。

YOLO · TXT

YOLO 数据集查看器

上传图片及对应的 TXT 标注，将归一化的中心坐标与宽高转换为检测框，显示类别编号。

class_id x_center y_center width height

打开 YOLO 查看器
COCO · JSON

COCO 数据集查看器

按文件名匹配 COCO JSON 中的图片，显示类别名称和检测框；支持搜索 Image ID、展开查看 JSON 结构。

bbox: [x, y, width, height]

打开 COCO 查看器
VOC · XML

Pascal VOC 数据集查看器

上传图片及对应的 Pascal VOC XML 标注，读取目标名称和左上、右下角坐标，显示带类别名称的检测框。

xmin, ymin, xmax, ymax

打开 VOC 查看器

三个查看器均可离线运行，每次查看一张图片，用于查看已有检测标注，不编辑标注。原工具界面保留中文；数据集下载及来源链接需要联网。
