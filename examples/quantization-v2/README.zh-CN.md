# 模型量化可视化 v2

[English](README.md) | **简体中文**

这是 `examples/quantization` 的重做版本：不再把各种浮点格式并排放，而是让一组权重完整走一遍线性量化 `q = clamp(round(x / s) + z)`、`x̂ = (q − z) × s`，同时看阶梯、误差分布、位宽扫描和存储账单。

双击 `index.html`，用 Edge、Chrome 等现代浏览器打开。全部代码与数据都在这一个文件里，无需安装依赖、启动服务器或联网。本工具由 AIHelper01 新制作，页面署名为“工具来源：AIHelper01”。

## 可以操作什么

- **位宽**：2／3／4／5／6／8 bit。对称模式码域为 `-127…127`，非对称模式为 `0…2^bit−1`。
- **量化方式**：对称共享一个 scale 且零点固定为 0；非对称额外给出零点，并保证 0 可精确表示。
- **分组粒度**：整张量共享 scale，或每 4／8／16 个权重一组一个 scale。
- **校准范围**：实测极值的 0.50×–1.50×。调窄阶梯更密但离群值会被截断；调宽不截断但阶梯变粗。
- **权重分布**：均匀、正态、长尾＋离群值（默认）——离群值正是让权衡看得见的关键。
- **权重量**与**舍入规则**：就近取偶（默认）、就近进位、向下取整。
- 按钮：**重新采样权重**、**恢复默认**、**选中下一个权重**。点击阶梯图中的权重点，或用 Tab 聚焦后按 Enter，即可查看该数的完整计算链。

## 怎么读图

- 蓝色阶梯是 `x` 到 `x̂` 的映射，虚线对角线是无误差参考 `x̂ = x`。
- 每个权重在对角线上有一个紫点（原始值）和一个橙方块（还原值），两者之间的连线长度就是这个数的误差。
- 被选中权重所在组的阶梯为实线，其余组为淡色，分组 scale 的差异一眼可辨。
- 被截断的权重用深色虚线连接，并落在码域端点上。
- 误差图按原始权重取值分箱给出每箱平均绝对误差；扫描图在当前设置下逐一重算各数位，柱为每参数字节、折线为均方误差。

## 计算约定与限制

- 对称：`Q = 2^(bit−1) − 1`，`scale = maxAbs × 校准倍率 / Q`，零点为 0，码域 `-Q…Q`，最负的补码编码不使用。非对称：无符号码 `0…2^bit−1`，校准范围包含 0，`scale = (hi − lo) / (2^bit − 1)`，零点四舍五入后再夹回码域。
- 默认中点取偶。所有还原值都落在格点 `(q − z) × scale` 上，因此未截断的误差不超过半个步长。
- 全零的组使用 `scale = 1`，仍可精确还原 0。
- 存储：打包整数载荷，加上每组 4 字节 FP32 scale；非对称模式每组再加 1 字节整数零点。这是教学格式的估算，浏览器并不真的打包权重，真实张量还有 tensor 级 scale、元数据、激活与 KV cache。
- 不做浮点位域编码、不做量化感知训练、不涉及激活与 KV cache 量化，也不对真实模型精度或推理速度下结论。
