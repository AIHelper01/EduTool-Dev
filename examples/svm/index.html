如何读这张图

边界与间隔：f(x) ≥ 0 判为正类，f(x) < 0 判为负类。蓝色实线是 f = 0，虚线是 f = ±1。背景颜色表示预测类别，f 是决策分数，不是概率。

支持向量：黑圈表示 α > 10⁻⁷。收敛时，0 < α < C 的样本通常位于间隔线上；α = C 的样本可能在间隔内或被分错。数值判断允许求解误差。

软间隔：ξ > 0 表示违反间隔要求，不一定是分类错误；只有实际与预测类别不同时才画红色 ×。C 调节模型复杂度与间隔违反惩罚的权衡。

核函数：线性核 K(x,z) = x·z；RBF 核 K(x,z) = exp(−γ‖x−z‖²)。RBF 的虚线是特征空间间隔在输入平面的投影，并不构成等宽的二维间隔带。
