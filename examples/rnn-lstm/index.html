RNN 与 LSTM：记忆怎样传递

把同一段输入按时间步送入两种网络，观察旧信息怎样留下、新信息怎样写入，以及下一步收到什么状态。

1. 先把循环展开成时间步

RNN 是循环神经网络；LSTM 是一种带门控的 RNN。这里“RNN”特指普通 tanh RNN。展开后的各个时间步使用同一套权重，不是每一步有一个独立模型。

单输入、单隐藏单元的真实前向计算。初始 h₀=C₀=0，不训练权重，不做语言预测。
f=1 全部保留旧 C；f=0 全部丢弃旧 C。
i=0 禁止写入候选值；i=1 全部写入。
o=0 隐藏输出为 0，但内部 C 可以继续保存。

参数或输入改变后会从零状态重新计算整段序列。这里的 0 表示仍在执行一个时间步，只是输入数值为零；不表示跳过该步。

2. 同一个时间步，内部怎样算？

普通 RNN：每次重算隐藏状态

旧 h → 乘循环权重 u → 加输入 x → tanh → 新 h
hᵣₜ = tanh(xₜ + u · hᵣₜ₋₁)

tanh 把输出限制在 −1…1。新输入与旧状态经过同一次非线性变换，记忆效果取决于权重和序列，不一定总是迅速遗忘。

LSTM：先保留与写入，再读出

旧 C → × f → ＋ i×候选值 g → 新 C → tanh → × o → 新 h
Cₜ = fₜCₜ₋₁ + iₜgₜ
hₜ = oₜ tanh(Cₜ)

C 是细胞状态，h 是隐藏状态。C 不局限在 −1…1；h 受 tanh 与输出门限制。候选值 g 使用 tanh，不是第四个 sigmoid 门。

4. 前面的输入，还能影响后面吗？

下面显示当前隐藏状态对第一个输入 x₁ 的导数。它表示“只稍微改变 x₁，当前输出会怎样变化”，可帮助理解反向传播中的梯度连乘；不是准确率或保留信息的百分比。

普通 RNN 的敏感度 ∂hᵣₜ/∂x₁

沿时间传播时，每一步乘 u·(1−hᵣₜ²)。u 小或 tanh 饱和时，影响可能快速衰减；符号也可能改变。

LSTM 的敏感度 ∂hₜ/∂x₁

包含 C 路径、输出 tanh 和门控的所有依赖。细胞状态的直接保留路径每步乘 f；这条路径不等于整个网络的总导数。

手动模式把门固定为常量，用来隔离门的作用；固定权重模式则包含门对旧 h 的依赖。LSTM 有助于长期依赖学习，但不能保证梯度永不消失或爆炸。

建议按这三步探索

① 保持“一次信号”，对比 u=0.5 与 f=0.95 的记忆变化。② 将 o 调到 0：h 消失，但 C 仍保留。③ 换成“反向信号”，调 i 与 f，观察新旧信息的取舍。
