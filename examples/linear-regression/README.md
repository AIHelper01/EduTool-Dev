# 线性回归参数练习（离线版）

双击 `index.html`，用 Edge、Chrome 等现代浏览器打开。无需安装软件或启动服务器，也无需联网。拖动 **Weight（权重）** 和 **Bias（偏置）** 滑块，可以观察拟合直线、各数据点的误差，以及 L1 Loss、L2 Loss、MSE 和 RMSE 的变化。

这是从 [Google 机器学习速成课程的参数练习页](https://developers.google.cn/machine-learning/crash-course/linear-regression/parameters-exercise?hl=zh-cn) 提取并封装的交互工具。原工具的脚本和数据保留在 `index.html` 内；原页面周边的站点导航没有包含在离线版里。数据集名称和工具内的按钮标签沿用原版英文。

本文件仅供本地学习与演示。原课程的[内容复用说明](https://support.google.com/machinelearningeducation/answer/7652594?hl=en)和页面上的版权声明仍适用；若计划再次发布或分发，请先查阅原站说明。
