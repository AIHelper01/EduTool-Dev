计算式与约定

    估算按 Pre-Norm 的 Decoder-only 结构计算矩阵权重，不含偏置、Router 之外的额外算子与激活值显存；KV 缓存按 FP16 / BF16 每元素 2 字节。MLA 的头维固定为 128 + 64（可旋转键），缓存 = 压缩潜变量 + 每头可旋转键。数值用于比较数量级，不等同于各模型官方公布值。
