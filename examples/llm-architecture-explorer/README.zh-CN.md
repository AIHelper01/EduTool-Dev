# 大模型层级结构互动演示

[English](README.md) | **简体中文**

直接双击 `index.html` 即可使用，不需要联网、安装或构建。已在全新浏览器上下文中阻断全部 HTTP(S) 请求验证过离线运行，页面无控制台报错。

本工具是按用户提供的静态结构图（`llm_architecture_full.html`）新制作的，配色与布局沿用本仓库浅色教学工具风格，不是从某个网页下载下来的原工具。

## 操作

- **预设**：Transformer 2017（解码器近似）、GPT-2 124M、LLaMA-3 8B、Mixtral 8×7B（MoE）、MLA + MoE 教学示例，另有不会被覆盖的自定义状态；“恢复预设值”回到上一次选择的预设。
- **方案选择**：位置编码（正弦／可学习／RoPE）、注意力（MHA／MQA／GQA／MLA）、归一化（LayerNorm／RMSNorm）、前馈结构（Dense／MoE）、前馈形式（2 矩阵／SwiGLU 3 矩阵）、输出层是否共享输入嵌入。
- **模型规模**：层数、隐藏维、注意力头数、前馈中间维、词表大小、上下文长度。
- **变体细节**：只在对应方案下生效——GQA 的 KV 头数、MLA 的 r<sub>q</sub> 与 r<sub>kv</sub>、MoE 的专家数与 Top-K；灰显项的含义写在该组下方，H<sub>kv</sub> 超过 H 时估算自动按 H 取上限。
- 结构图里的 MHA／MQA／GQA／MLA 标签可以直接点击切换注意力；柱状图上方三个按钮分别切换“每 Token 每层 KV 缓存”“每层注意力参数”“每层前馈参数”，紫色柱即当前选择，并给出相对基准的倍数。

结构图文字、柱状图、指标列表和计算式都由同一份状态渲染，不会出现某个数字没跟着变的情况。

宽于 1200 px 时，控件在左列，层级结构图固定在右列并带独立滚动条，调参数时两边同屏联动；窄于此宽度自动回到单列，顺序为控件 → 结构图 → 对比图 → 指标。

## 计算约定

按 Pre-Norm 的 Decoder-only 结构估算，只统计矩阵权重，不含偏置，也不含 Router 之外附加的算子。

- 注意力（MHA／MQA／GQA）：`2·d·(H·d_h) + 2·d·(H_kv·d_h)`，其中 `d_h = d/H`。
- 注意力（MLA）：`d·r_q + r_q·H·(d_c+d_r) + d·r_kv + r_kv·H·(d_c+d_r) + H·d_c·d`，头维固定 `d_c = 128`、可旋转键 `d_r = 64`。
- 每 Token 每层 KV 缓存：`2·H_kv·d_h` 个数，MLA 为 `r_kv + H·d_r` 个数，均按 FP16／BF16 每元素 2 字节计。
- 前馈：`2·d·d_ff`，SwiGLU 为 `3·d·d_ff`；MoE 按专家数放大并加一个 `d×E` 的 Router，激活量只算 Top-K 个专家。
- 可学习位置嵌入额外占 `L×d`，正弦与 RoPE 不占参数。
- 总量：`V·d + 位置 + N·(注意力 + 前馈 + 2×Norm) + Norm + LM Head`；每 Token 前向计算量按 `2×激活参数` 近似。

## 限制

- 以上是公式估算，与官方公布值可能有差异。页面实测：GPT-2 124.4M、LLaMA-3 8B 8.03B、Mixtral 8×7B 总量 46.70B／激活 12.88B、LLaMA-3 每 Token 每层 KV 缓存 4.0 KB（上下文 2048 时 256.0 MB）。
- Transformer 2017 预设只搭了解码器主干，因此比论文的 65M 编码器–解码器计数小；MLA 预设借用了 DeepSeek-V2 的注意力与 MoE 设置，层数减少且没有共享专家，属于教学示例而非官方配置，其缓存假设“一份共享压缩潜变量 + 每头可旋转键”。
- 不做训练、不做推理，也不建模显存与延迟：激活显存、专家并行开销、量化缓存以及各方案对精度的影响都不在范围内。
