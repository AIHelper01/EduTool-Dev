LoRA 低秩适配可视化

保留已有模型，用两个小矩阵学习“要改什么”。从权重更新、参数量到训练和合并，逐步看懂 Low-Rank Adaptation。

1. 原权重不动，学习一个低秩更新

W′ = W₀ + (α / r) · B · A

本例是一层 8 输入、8 输出的线性层。W₀ 为 8×8，始终冻结；A 为 r×8，把输入投影到 r 维；B 为 8×r，把这 r 个方向映射回 8 维。更新矩阵 ΔW = (α/r)BA 的秩至多为 r。

改变 r 或目标会重新初始化 A/B；改变 α 保留 A/B，但会改变当前更新大小并重计损失。
全量更新 W₀648×8 个可训练参数
LoRA 可训练参数A + B：r×8 + 8×r
可训练参数占比只比较这一层，不含冻结的 W₀
当前缩放 α/r不是学习率；r 也不是实际矩阵秩

低秩限制的是“更新”ΔW，原矩阵 W₀ 和适配后的 W′ 不要求低秩。这个小例子在 r=4 时已不节省参数；真实模型通常满足 r ≪ 输入/输出维数。

紫色＝正值，橙色＝负值，浅色＝接近零；各矩阵共用 ±2 的颜色刻度，超出时颜色饱和，数字保留实际值。点击 A/B 可编辑；点击 ΔW 或 W′ 可拆解一个元素。显示值做了舍入，计算使用完整精度。

一个更新元素怎样算出来？

B 的一行与 A 的一列做点积，再乘 α/r；加上同一位置的 W₀，就得到 W′。

2. 训练时，只更新 A 和 B

合成任务给出一个目标更新 T。训练让 (α/r)BA 接近 T，W₀ 全程不动。目标为对角矩阵：秩 1 任务只有一个非零对角元素；秩 3 任务有 1、0.8、0.6 三个独立方向。

误差随训练下降

目标更新 T · 8×8

A 使用固定种子的随机初始化，B 从零开始，因此初始更新为零。两者都为零会让梯度也为零，无法启动学习。这里用带回溯的梯度下降展示机制，实际微调常用 Adam 等优化器；理论下界不保证有限步训练一定达到。此误差也不是语言模型的准确率。

3. 输入走两条路；推理时可以合并

其余 7 个分量固定为 [0.5, −0.5, 0.2, 0, 0.3, −0.2, 0.1]，只演示这一层，无偏置和激活函数。

原模型支路：x → W₀x
LoRA 支路：x → Ax（r 维）→ B(Ax)（8 维）→ 乘 α/r

保留两条支路

y = W₀x + (α/r)B(Ax)

把适配器合并进权重

W′ = W₀ + (α/r)BA；y = W′x

合并只改变计算方式，没有再训练；对这层的固定适配器，两种输出在实数运算中相等。合并后可复用原线性层推理路径，避免额外支路运算；实际速度与数值精度取决于实现，训练时的 dropout 等也不能直接用这个简化等式替代。

4. 放大到真实矩阵，参数为什么省？

沿用当前 r：
全量：d×k
LoRA：r×(d+k)

柱条为 LoRA / 全量更新的可训练参数占比。省的是可训练参数、对应梯度/优化器状态和每个适配器的存储，冻结基础模型仍然要保留。实际训练显存还包括激活等，不能直接按这个比例换算。LoRA 不等于量化：QLoRA 则另外量化基础权重。
