# 分类准确率、精确率与召回率（离线版）

双击 `index.html`，用 Edge、Chrome 等现代浏览器打开。无需安装软件或启动服务器，也无需联网。

选择 **Separated**、**Unseparated** 或 **Imbalanced** 数据集，再拖动 **Classification threshold（分类阈值）**，即可观察图表、混淆矩阵和 Accuracy（准确率）、Precision（精确率）、Recall（召回率）的变化。

本文件提取并封装了 [Google 机器学习速成课程对应页面](https://developers.google.cn/machine-learning/crash-course/classification/accuracy-precision-recall?hl=zh-cn) 的交互脚本和数据。原页面周边的站点导航没有包含在离线版里。再次发布或分发时，请先查阅[原课程的内容复用说明](https://support.google.com/machinelearningeducation/answer/7652594?hl=en)。
